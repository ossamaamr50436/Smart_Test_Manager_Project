# منصة مدير الاختبارات الذكي الشامل

> **جمعية تعليم القرآن وعلومه — فرع المدينة المنورة**

منصة رقمية متكاملة لإدارة الاختبارات الشفهية لحفظ القرآن الكريم: من ترشيح الجهات التعليمية للطلاب، إلى تشكيل اللجان، والتقييم الحي متعدد المقيّمين، والاعتماد المتسلسل حسب العمر، حتى إصدار الشهادات ورفعها على Google Drive.

---

## ✨ المميزات الرئيسية

- **الترشيح والإشراف**: كل جهة تعليمية ترشّح طلابها وتتابع حالتهم فقط (عزل صارم للصلاحيات).
- **التقييم الحي المشترك**: معلمان لكل طالب (لجنة) مع مصابحة لحظية عبر WebSocket والمزامنة بين المقيّمين.
- **الاعتماد المتسلسل حسب العمر (المادة 5)**: الأكبر سناً يعتمد أولاً، ثم الأصغر يعتمده نهائياً — لا يمكن تجاوز الترتيب.
- **منع تكرار النموذج (المادة 6)**: لا يمكن لطالبين استخدام نفس النموذج في نفس الموسم.
- **الشهادات الرقمية**: توليد PDF عربي وتوقيع رقمي ورفع حصري على Google Drive.
- **سجل تدقيق شامل (Audit Log)**: توثيق كل عملية حساسة مع الفلاتر والبحث.
- **نظام إشعارات**: للمعلمين والجهات والأخصائيين في كل مرحلة.
- **إعدادات ديناميكية**: اسم المنصة وشعارها قابلان للتحديث دون إعادة نشر.

## 🧱 البنية التقنية (المادة 4)

| المكوّن | التقنية |
|---|---|
| الإطار | Next.js 14 (App Router) + TypeScript (Strict) |
| الواجهات | Tailwind CSS + Shadcn/ui (RTL عربي كامل) |
| قاعدة البيانات | Neon PostgreSQL (سحابي) عبر Prisma |
| المصادقة | NextAuth.js v5 (Credentials + JWT) |
| التزامن اللحظي | Socket.IO (مزامنة التقييم بين المعلمين) |
| تخزين الملفات | Google Drive فقط عبر Service Account |
| الاستضافة | Vercel (Serverless) |

## 🗄️ الأدوار والصلاحيات (المادة 8)

1. **الجهة التعليمية (Institution)**: ترشيح الطلاب ومتابعة طلاب جهتها فقط.
2. **المختبر/المعلم (Examiner)**: تقييم الطلاب الموزعين على لجانه فقط.
3. **أخصائي الاختبارات (Test Specialist)**: مراجعة الطلبات، تشكيل اللجان، والاعتماد الإداري — دون توقيع الشهادات.
4. **رئيس الشؤون التعليمية (Head of Affairs)**: الاطلاع على الدرجات المعتمدة والاعتماد النهائي — دون دخول واجهة التقييم الحي.
5. **مصدر الشهادات (Certificate Source)**: إصدار الشهادات للطلاب المكتملين فقط.
6. **المسؤول (Admin)**: صلاحيات كاملة مع تسجيل أي تدخل في سجل التدقيق.

## 📋 المتطلبات التقنية

- Node.js **18.17+** (موصى به 20 LTS)
- مدير الحزم **pnpm** (إصدار 9+)
- حساب [Neon](https://neon.tech) لقاعدة بيانات PostgreSQL سحابية
- حساب خدمة Google Cloud مع تفعيل Drive API

## 🚀 التشغيل محلياً

```bash
# 1) تثبيت الاعتماديات
pnpm install

# 2) إعداد متغيرات البيئة
# انسخ .env.example إلى .env واملأ القيم الحقيقية (Neon + NextAuth + Google Drive)
cp .env.example .env

# 3) توليد عميل Prisma وتجهيز قاعدة البيانات
pnpm prisma:generate
pnpm prisma:push   # أو pnpm prisma:migrate

# 4) تهيئة الحساب الإداري الأول
pnpm db:seed

# 5) التشغيل
pnpm dev
```

ثم افتح <http://localhost:3000>.
