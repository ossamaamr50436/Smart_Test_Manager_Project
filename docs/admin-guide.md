# دليل المسؤول (Admin Guide)

دليل تفصيلي للمسؤول العام للنظام: إدارة المستخدمين والجهات والنماذج والمواسم ومراجعة سجل التدقيق.

## الدور والصلاحيات

المسؤول (ADMIN) هو **الدور الوحيد** الذي يستطيع:
- إنشاء/تعديل/حذف المستخدمين من كل الأدوار.
- إدارة إعدادات المنصة (الاسم، الشعار، إعلان الشاشة).
- تحديث إعدادات المواسم (إنشاء موسم وتنشيطه).
- الإشراف على البيانات (الجهات، الطلاب، النماذج، الجلسات) وحذفها عند الحاجة.
- الاطلاع الكامل على **سجل التدقيق**.

المسؤول **لا يدخل واجهة التقييم الحي** ولا يوقّع الشهادات (مفصولة بموجب المادة 8).

## المواسم (Seasons)

1. من صفحة **المواسم** ← أنشئ موسماً جديداً (اسم + تاريخ البداية/النهاية).
2. **فعّل** موسيماً واحداً فقط كواحد نشط — كل الجلسات الجديدة وتوزيع النماذج ترتبط بالموسم النشط.
3. لا يمكن إنشاء جلسة بدون موسم نشط (محجوب برمجياً — انظر اختبارات `business-logic`).

## النماذج الاختبارية (حسب لائحة الخاتمين)

- كل نموذج: **10 مقاطع**، وكل مقطع **7 حقول** (من/إلى قوله تعالى + السورة + الآية).
- الأفرع المعتمدة: `5, 10, 15, 20, 25, 30` جزءاً.
- عدد النماذج لكل فرع: **1–20** (قيد فريد: `[الجهة، رقم النموذج، الموسم، الفرع]`).
- إنشاء/تعديل/حذف النماذج **حصراً للأخصائي والمسؤول** — لا يمكن حذف نموذج سبق استخدامه في تقييمات أو جلسات.
- الاستيراد الجماعي متاح عبر `/api/import/models` (يطلب `branch` و `seasonId` ورقم 1–20).

## إدارة المستخدمين

عند إنشاء مستخدم جديد انتبه:
- **كلمة المرور** تُرسل للمستخدم عبر رسالة إعداد (يُنصح بالتغيير الفوري).
- **المعلمون (EXAMINER)**: يجب تعبئة **تاريخ الميلاد** — يعتمد عليه ترتيب الاعتماد العمري (المادة 5).
- **الجهة (INSTITUTION)**: ربط الحساب بجهة تعليمية موجودة مسبقاً.
- عند ظهور رسالة "لا يمكن الحذف — الحساب مرتبط بعمليات"، عطّل الحساب بدل الحذف.

## الضوابط التشغيلية

- الطالب في حالة `APPROVED` بعد موافقة الأخصائي؛ ولا تُوزَّع اللجان إلا للموافق عليهم.
- عند تشكيل لجنة تلقائياً، يُضبط النظام أن الطالب يحصل على **معلمَين اثنين** فقط (كبير + صغير عمراً لضمان ترتيب الاعتماد).
- حالة الطالب تتقدم تلقائياً: `PENDING → APPROVED → ASSIGNED → COMPLETED`.

## سجل التدقيق (Audit Log)

كل عملية حساسة تُسجَّل: إنشاء/تعديل/حذف النماذج، حفظ التقييمات، الاعتماد، توليد الشهادات، تغيير الإعدادات. استخدم فلاتر الدور والتاريخ للبحث. سجل التدقيق متاح **للمسؤول والأخصائي فقط**.

## مراجعة دورية (Checklist)

- [ ] موسم نشط واحد فقط موجود.
- [ ] كل النماذج مرتبطة بجهة وموسم وفرع صحيح.
- [ ] لا حسابات معلّق بدون تعيينات.
- [ ] راجع آخر المخالفات في سجل التدقيق أسبوعياً.
- [ ] النسخة الاحتياطية: قاعدة بيانات Neon تُأخذ من لوحة Neon (PITR أو تصدير مؤقت).
