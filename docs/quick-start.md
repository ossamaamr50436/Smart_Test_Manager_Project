# دليل البدء السريع (Quick Start)

## المتطلبات

- Node.js **18.17+** (موصى به 20 LTS)
- **pnpm** 9+
- قاعدة بيانات [Neon](https://neon.tech) PostgreSQL سحابية
- (اختياري) حساب خدمة Google Cloud مع تفعيل Drive API وبيانات Pusher للمزامنة اللحظية

## خطوات الإعداد (5 دقائق)

```bash
# 1) تثبيت الاعتماديات
pnpm install

# 2) إعداد متغيرات البيئة — انسخ المثال واملأ القيم
cp .env.example .env

# 3) توليد عميل Prisma وتطبيق المخطط على قاعدة البيانات
pnpm prisma:generate
pnpm prisma:migrate     # ينشئ الهجرات ويطبقها (أو pnpm prisma:push)

# 4) بذر البيانات التجريبية (87 جهة، 100 نموذج، 250 طالباً، 13 لجنة)
pnpm db:seed

# 5) تشغيل بيئة التطوير
pnpm dev
```

افتح <http://localhost:3000>.

## الحسابات التجريبية

البيذر يُنشئ حساب مسؤول من متغيرات البيئة:

| المتغير | القيمة المبدئية |
|---|---|
| `ADMIN_EMAIL` | `admin@example.com` |
| `ADMIN_PASSWORD` | `QuranAdmin2026!Strong` |

بالإضافة إلى حسابات أدوار بمصافحة واحدة `QuranTest2026!Strong`:

| الدور | البريد |
|---|---|
| أخصائي الاختبارات | `specialist@example.com` |
| رئيس الشؤون التعليمية | `head.affairs@example.com` |
| مصدر الشهادات | `certificate.source@example.com` |
| معلم مختبر (لجنة) | `ahmed.mohammad@example.com` |

> ⚠️ غيّر كلمات المرور فوراً في بيئة إنتاج حقيقية.

## سير العمل المختصر للتجربة

1. ادخل بحساب **الأخصائي** ← أضف نموذجاً اختبارياً من صفحة **النماذج** (10 مقاطع).
2. ادخل بحساب **الجهة** ← رشّح طالباً جديداً.
3. **الأخصائي** يراجع الطلب ← يشكّل لجنة (معلمين اثنين + موعد + نموذج).
4. **المعلم المختبر** يفتح التقييم ← يسجّل الأخطاء وفق اللائحة (100 درجة) ← **اعتماد تقييمي** (كل مختبر يعتمد مستقلاً).

## الأوامر المتاحة

```bash
pnpm dev                 # بيئة التطوير
pnpm build && pnpm start # إنتاجي
pnpm typecheck           # فحص الأنواع
pnpm test                # اختبار الوحدة + الأمان + التكامل
pnpm test:load           # اختبار الحمل (المسار الحرج للدرجات)
pnpm e2e:install         # تثبيت متصفحات Playwright (مرة واحدة)
pnpm test:e2e            # اختبارات E2E (بعد تشغيل pnpm dev)
pnpm prisma:studio       # تصفح قاعدة البيانات
```

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `DATABASE_URL` غير صالح | أعد إنشاء قاعدة على Neon وحدّث `.env` |
| **البيذر يرفض العمل** | يجب توفير `ADMIN_EMAIL` + `ADMIN_PASSWORD` القوي (12+ حرفاً) |
| المزامنة اللحظية لا تعمل | تحقق من مفاتيح Pusher أو فعّل وسائط الاستبدال في `NEXT_PUBLIC_*` |
| النماذج لا تظهر | أعد `pnpm db:seed` وتأكد من الموزن النشط عبر `/admin/seasons` |
