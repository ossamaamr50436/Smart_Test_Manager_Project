🔴 المرحلة 4: إضافة نموذج Tenant

**الملف:** `prisma/schema.prisma`

**أضف هذا قبل `model User {` مباشرة:**

```prisma
// ============================================================
// Multi-Tenant — المؤسسات/الجمعيات
// ============================================================
model Tenant {
  id              String   @id @default(cuid())
  name            String   @unique
  slug            String   @unique
  driveFolderId   String?
  driveFolderUrl  String?
  primaryColor    String   @default("#015e63")
  secondaryColor  String   @default("#d3bb8b")
  isActive        Boolean  @default(true)
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt

  // Relations
  users               User[]
  institutions        Institution[]
  students            Student[]
  examSeasons         ExamSeason[]
  examModels          ExamModel[]
  committees          Committee[]
  examSessions        ExamSession[]
  assessments         Assessment[]
  certificates        Certificate[]
  notifications       Notification[]
  auditLogs           AuditLog[]
  assessmentSettings  AssessmentSettings?

  @@map("tenants")
}
```

**⚠️ تنبيه:**
- **لا تُنشئ `TenantBranding`**.
- **لا تلمس `AppSettings`** (تبقى global).
- **لا تلمس `RateLimit`** (تبقى global).

**التحقق:**
```powershell
Select-String -Path "prisma\schema.prisma" -Pattern "model Tenant"
```
