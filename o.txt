🔴 المرحلة 1: تشخيص خطأ إنشاء الحساب في الإنتاج

**المطلوب:**

2. **تحقق من Migration المطبَّق على Neon:**
   - نفّذ `pnpm prisma migrate status`
   - إذا وُجد migration معلّق → نفّذ `pnpm prisma migrate deploy`
   - تحقق أن عمود `mustChangePassword` موجود على جدول `users` في Neon:
     ```typescript
     const result = await prisma.$queryRaw`
       SELECT column_name FROM information_schema.columns 
       WHERE table_name = 'users' AND column_name = 'mustChangePassword'
     `;
     console.log(result);
     ```

3. **أعد إنتاج الخطأ محلياً في وضع الإنتاج:**
   - `pnpm build && pnpm start`
   - افتح `http://localhost:3000`
   - سجّل دخول كأدمن، واذهب إلى `/admin/users`
   - جرّب إنشاء حساب جديد
   - **انسخ رسالة الخطأ الكاملة** من Terminal

4. **حدد السبب الجذري** وثّقه في التقرير.

5. **أصلح السبب** (بأقل تعديل ممكن) — على الأرجح:
   - Migration غير مطبّق على Neon → طبّقه
   - حقل مفقود في Zod schema → أضفه
   - عدم توافق بين العميل والخادم → أعد توليد Prisma Client
   - مشكلة في `mustChangePassword` عند قراءته أثناء الجلسة → أصلح المنطق

6. **أضف معالجة أخطاء واضحة في Server Action**:
   ```typescript
   try {
     const created = await prisma.user.create({ ... });
     return { success: true, userId: created.id };
   } catch (error) {
     if (error instanceof Prisma.PrismaClientKnownRequestError) {
       if (error.code === "P2002") {
         throw new Error("تعذّر إنشاء الحساب — تحقق من البيانات المدخلة");
       }
       if (error.code === "P2022" || error.code === "P2021") {
         // schema mismatch
         throw new Error("خطأ في مزامنة قاعدة البيانات — تواصل مع المسؤول");
       }
     }
     throw new Error("حدث خطأ غير متوقع");
   }
   ```

7. **أعد الاختبار محلياً** (`pnpm build && pnpm start`) حتى ينجح إنشاء الحساب.

## 📋 ملاحظاتي قبل التشغيل

### 1️⃣ لماذا اخترت القائمة المنسدلة أسفل الشريط؟

| النمط | المميزات | العيوب |
| :--- | :--- | :--- |
| **زر مباشر في الشريط** | بسيط | يشغل مساحة، أقل احترافية |
| **ثلاث نقاط في الأعلى** | شائع | بعيد عن العين |
| ✅ **قائمة منسدلة أسفل الشريط** | احترافي، يجمع كل شيء، ثابت | يحتاج تطبيق جديد |

**القرار**: القائمة المنسدلة أسفل الشريط — معيار التطبيقات الحديثة (Notion، Linear، Vercel نفسه).

Vercel حذّر في اللوجات:
```
Warning: Detected "engines": { "node": ">=18.17.0" } in your package.json
```

لأن Vercel قد يستخدم Node 24 (الذي أظهرته اللوجات!). التنصيص على `>=20.0.0 <21.0.0` يضمن بيئة مستقرة.

### 3️⃣ لماذا `vercel.json` منفصل؟

يوفر:
- إعدادات موحدة (لا تعتمد على Vercel Dashboard).
- يمكن تعديله من Git مباشرة.
- يقلل الأخطاء البشرية.
