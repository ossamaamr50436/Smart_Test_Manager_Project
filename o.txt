🔴 المهمة 1: تحويل `createAdminUser` من throw إلى return

**الملف:** `lib/actions/admin-panel-actions.ts`

**التغيير المطلوب:**

```typescript
// ===== قبل =====
export async function createAdminUser(input: unknown) {
  const user = await requireUser();
  requireRole(user, [Role.ADMIN]);
  
  // ... Zod validation
  throw new Error("البريد الإلكتروني غير صالح");  // ❌ محجوب في الإنتاج
}

// ===== بعد =====
export type CreateUserResult =
  | { success: true; userId: string }
  | { success: false; error: string; fieldErrors?: Record<string, string> };

export async function createAdminUser(input: unknown): Promise<CreateUserResult> {
  try {
    const user = await requireUser();
    requireRole(user, [Role.ADMIN]);
  } catch (e) {
    return { success: false, error: "غير مصرح — يجب أن تكون أدمن" };
  }

  // Zod validation
  const parsed = createUserSchema.safeParse(input);
  if (!parsed.success) {
    const fieldErrors: Record<string, string> = {};
    for (const issue of parsed.error.issues) {
      const field = issue.path.join(".");
      fieldErrors[field] = issue.message;
    }
    return {
      success: false,
      error: `تحقق من البيانات: ${Object.values(fieldErrors).join(" | ")}`,
      fieldErrors,
    };
  }

  const data = parsed.data;
  const hashedPassword = await bcrypt.hash(data.password, 12);

  try {
    const created = await prisma.user.create({
      data: { ...data, password: hashedPassword },
    });
    
    // Audit (بمعالجة مستقلة)
    try {
      await recordAudit(user.id, AuditAction.CREATE, { ... });
    } catch {}

    revalidatePath("/admin/users");
    return { success: true, userId: created.id };
  } catch (error) {
    if (error instanceof Prisma.PrismaClientKnownRequestError) {
      if (error.code === "P2002") {
        return { success: false, error: "البريد الإلكتروني مستخدم بالفعل" };
      }
      if (error.code === "P2022" || error.code === "P2021") {
        return { success: false, error: "خطأ في مزامنة قاعدة البيانات" };
      }
    }
    console.error("createAdminUser failed:", error);
    return { success: false, error: "حدث خطأ غير متوقع — تحقق من السجلات" };
  }
}
```

🔴 المهمة 2: تحديث `admin-users-manager.tsx` لاستقبال النتيجة

**الملف:** `components/admin/admin-users-manager.tsx`

**التغيير المطلوب:**

```typescript
// ===== قبل =====
try {
  await createAdminUser(data);
  setMessage("تم إنشاء المستخدم بنجاح");
} catch (e) {
  setError("حدث خطأ غير متوقع");  // ❌ رسالة عامة
}

// ===== بعد =====
const result = await createAdminUser(data);

if (result.success) {
  setMessage("تم إنشاء المستخدم بنجاح");
  setError("");
  // إعادة تعيين النموذج
} else {
  setError(result.error);  // ✅ عرض الخطأ الحقيقي
  setMessage("");
  if (result.fieldErrors) {
    // اختياري: عرض الأخطاء تحت كل حقل
    console.log("Field errors:", result.fieldErrors);
  }
}
```

**نفس النمط** يُطبَّق على كل Server Action تُستدعى من هذا المكوّن (تعديل، حذف، إعادة تعيين).

🔴 المهمة 4: إصلاح البريد في `lib/validations/user.ts`

**استبدل `z.string().email()` بـ regex متسامح:**

```typescript
email: z
  .string()
  .trim()
  .toLowerCase()
  .min(1, "البريد الإلكتروني مطلوب")
  .max(254, "البريد الإلكتروني طويل جداً")
  .regex(
    /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/,
    "البريد الإلكتروني غير صالح (مثال: name@domain.com)"
  ),
```

**سبب الاستبدال:**
- `z.string().email()` صارم جداً ويرفض حالات مشروعة.
- `trim()` يزيل المسافات (شائعة عند النسخ واللصق).
- `toLowerCase()` يوحّد البريد.
- Regex البسيط يقبل أي بريد معقول.
