🔴 المهمة 1: محتوى التعليم والدور لجميع الأدوار

### 1.1 الفحص الأولي

```powershell
Get-Content "app\(dashboard)\settings\tutorial\page.tsx"
```

افهم البنية الحالية لكائن `GUIDANCE`.

### 1.2 المطلوب

افتح `app/(dashboard)/settings/tutorial/page.tsx`، واحرص على وجود **7 مفاتيح كاملة** في كائن `GUIDANCE`:

```typescript
const GUIDANCE: Record<string, Guidance> = {
  SUPER_ADMIN: { ... },         // مالك المنصة
  ADMIN: { ... },                // مشرف المؤسسة
  HEAD_OF_AFFAIRS: { ... },      // رئيس الشؤون التعليمية
  CERTIFICATE_SOURCE: { ... },   // مصدر الشهادات
  TEST_SPECIALIST: { ... },      // أخصائي الاختبارات
  EXAMINER: { ... },             // المختبر (المعلم)
  INSTITUTION: { ... },          // الجهة التعليمية
};
```

**كل دور يحتوي على:**
- `title`: اسم الدور الرسمي.
- `intro`: ملخص من سطرين.
- `sections`: 3-6 أقسام، كل قسم فيه `heading` + `items` (نقاط واضحة).

### 1.4 التأكد من عدم وجود "لا يوجد محتوى" لأي دور

أضف احتياطياً في نهاية الملف (بعد `GUIDANCE`):

```typescript
// في الكود الذي يستخدم GUIDANCE:
const guidance = role ? GUIDANCE[role] : undefined;
```

**إذا `role` غير موجود، يظهر "لا يوجد محتوى".**
**تأكد أن كل دور في enum Role له مفتاح.**

🔴 المهمة 2: إصلاح تباين Dark Mode

### 2.1 الفحص

```powershell
Get-Content "components\ui\button.tsx"
Select-String -Path "components\**\*.tsx" -Pattern "hover:bg-white|hover:bg-gray-|hover:text-black|hover:bg-secondary-50" -SimpleMatch | Select-Object -First 30
```

### 2.2 الحل

**القاعدة الذهبية:** لا تستخدم ألواناً ثابتة في Hover. استخدم متغيرات دلالية:

**في `components/ui/button.tsx`:**

```typescript
variants: {
  variant: {
    default: "bg-gradient-to-r from-primary-500 to-primary-700 text-white shadow-md hover:from-primary-600 hover:to-primary-800 hover:shadow-lg",
    destructive: "bg-gradient-to-r from-red-500 to-red-600 text-white shadow-sm hover:from-red-600 hover:to-red-700",
    outline: "border border-input bg-background text-foreground shadow-sm hover:bg-accent hover:text-accent-foreground",
    secondary: "bg-secondary text-secondary-foreground shadow-sm hover:bg-secondary/80",
    ghost: "hover:bg-accent hover:text-accent-foreground",
    link: "text-primary underline-offset-4 hover:underline",
  },
}
```

**في كل المكونات:**

| قبل | بعد |
| :--- | :--- |
| `hover:bg-white` | `hover:bg-accent` |
| `hover:bg-gray-50` | `hover:bg-muted` |
| `hover:bg-secondary-50` | `hover:bg-accent` |
| `hover:bg-secondary-100` | `hover:bg-accent` |
| `hover:text-black` | `hover:text-accent-foreground` |

### 2.3 إضافات ضرورية في `.dark` (globals.css)

```css
.dark {
  /* ... المتغيرات الموجودة ... */
  
  /* تأكيد تباين الأزرار */
  --accent: #1a262e;
  --accent-foreground: #eef1f4;
  --muted: #1a262e;
  --muted-foreground: #9fb3c0;
}
```

### 2.4 الاختبار

في الوضع الليلي، جرّب Hover على:
- كل أزرار `/super-admin/*`.
- كل أزرار `/admin/*`.
- كل أزرار `/test-specialist/*`.
- القائمة المنسدلة.
- Sidebar.
- Dialogs والـModals.

**المتوقع**: النص يبقى مرئياً بوضوح.
