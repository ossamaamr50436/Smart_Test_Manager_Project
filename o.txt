🔴 المهمة 1 (الأهم): إصلاح مشكلة الأزرار التي تحتاج ضغطات متعددة

**المشكلة الوصفية:**
- المستخدم يضغط على زر (مثل "دخول" أو "حفظ") فلا ينفذ من المرة الأولى.
- يحتاج لضغطه 2-3 مرات.
- المشكلة تحدث في **كل الأزرار** في المنصة.

**الأسباب المحتملة (افحصها بالترتيب):**

**A) مشكلة Hydration في Next.js:**
- افحص `app/layout.tsx` و `app/(dashboard)/layout.tsx`.
- إذا كان هناك مكوّن `"use client"` داخل Server Component بشكل خاطئ، قد يؤدي لتأخر Hydration.
- ابحث عن تحذيرات Hydration في Console.

**B) مشكلة `asChild` في Radix UI:**
- افحص `components/ui/button.tsx`.
- إذا كان الزر مغلّفاً بـ`DropdownMenuTrigger` أو `DialogTrigger` مع `asChild`، قد يستهلك الحدث.
- تأكد من أن `<Button>` يستخدم `forwardRef` بشكل صحيح.

**C) مشكلة `pointer-events` أو `z-index`:**
- افحص CSS العام (`app/globals.css`).
- إذا كان هناك عنصر متراكب (overlay, backdrop) بشفافية كاملة، قد يمنع النقرات.
- تحقق من `lib/csp.ts` — قد يكون CSP يحجب بعض السكربتات.

**D) مشكلة `form` submission في صفحة الدخول:**
- افحص `app/(auth)/login/page.tsx`.
- تأكد أن `<form onSubmit>` يستخدم `e.preventDefault()` بشكل صحيح.
- إذا كان `signIn` من NextAuth يستخدم `redirect: false`، تأكد من معالجة الرد.
- **الحل الشائع**: استخدام `startTransition` أو `useActionState` أو حالة `loading` لمنع التكرار.

**E) مشكلة إعادة الرسم (Re-rendering):**
- افحص `components/providers/*.tsx`.
- إذا كان Provider يُعيد رسم الشجرة كاملة عند كل تغيير، قد يتأخر الاستجابة.

**المطلوب:**
1. حدد السبب الجذري (أو الأسباب) بأدلة.
2. طبّق الحل في كل مكان فيه زر:
   - **صفحة الدخول** (`app/(auth)/login/page.tsx`).
   - **كل النماذج** (`components/**/*form*.tsx` و `components/**/*manager*.tsx`).
   - **أزرار الشريط الجانبي والقوائم**.
3. الحل المعتمد (طبّقه بشكل موحّد):
   - استخدم `<Button type="submit" disabled={isLoading}>` مع حالة `isLoading`.
   - داخل Server Action، استخدم `useTransition` أو `useFormStatus`.
   - تأكد من أن `onClick` لا يستدعي `preventDefault` أو `stopPropagation` بلا داعٍ.
4. بعد الإصلاح، اختبر يدوياً:
   - الضغط **مرة واحدة** على زر الدخول → ينجح.
   - الضغط **مرة واحدة** على أي زر حفظ → ينجح.
   - الضغط **مرة واحدة** على تسجيل الخروج → ينجح.

🔴 المهمة 3: نظام ألوان متدرج (Gradients) احترافي

**المشكلة:**
- المنصة حالياً تستخدم لونين ثابتين فقط (primary + secondary).
- المطلوب: نظام ألوان **متدربج** (Gradient System) احترافي.

**المطلوب:**

**3.1 في `app/globals.css` أضف:**
- متغيرات CSS جديدة للتدرجات:
  ```css
  --gradient-primary: linear-gradient(135deg, hsl(var(--primary)) 0%, hsl(var(--primary-600)) 100%);
  --gradient-secondary: linear-gradient(135deg, hsl(var(--secondary)) 0%, hsl(var(--secondary-600)) 100%);
  --gradient-success: linear-gradient(135deg, #10b981 0%, #059669 100%);
  --gradient-warning: linear-gradient(135deg, #f59e0b 0%, #d97706 100%);
  --gradient-danger: linear-gradient(135deg, #ef4444 0%, #dc2626 100%);
  --gradient-sidebar: linear-gradient(180deg, hsl(var(--primary-700)) 0%, hsl(var(--primary-900)) 100%);
  --gradient-card-hover: linear-gradient(135deg, hsl(var(--card)) 0%, hsl(var(--primary-50)) 100%);
  ```

**3.2 في `tailwind.config.ts`:**
- أضف ألواناً موسّعة لكل درجة primary-50 → primary-900.
- مثال:
  ```
  primary: {
    50: '#f0f9fa', 100: '#d9f0f2', ..., 500: '#015e63', 600: '#014f53', ..., 900: '#002225'
  }
  ```
- طبّق نفس المنهج على secondary.

**3.3 طبّق التدرجات في:**

**أ) الشريط الجانبي:**
- الخلفية: `bg-gradient-to-b from-primary-700 to-primary-900`.
- العناصر النشطة: `bg-gradient-to-r from-primary-500 to-primary-600`.
- أيقونات بلون أبيض.

**ب) الأزرار الرئيسية:**
- `bg-gradient-to-r from-primary-500 to-primary-700 hover:from-primary-600 hover:to-primary-800`.
- ظل: `shadow-md hover:shadow-lg`.

**ج) البطاقات (Cards):**
- عند Hover: `hover:bg-gradient-to-br hover:from-card hover:to-primary-50`.
- حدود متدرجة: `border-gradient` (استخدم pseudo-element إذا لزم).

**د) الشارات (Badges):**
- النجاح: `bg-gradient-to-r from-emerald-500 to-emerald-600`.
- التحذير: `bg-gradient-to-r from-amber-500 to-amber-600`.
- الخطأ: `bg-gradient-to-r from-red-500 to-red-600`.

**هـ) الشريط العلوي:**
- خلفية: `bg-gradient-to-r from-card via-card to-primary-50`.

**3.4 الشهادات (إن وُجدت):**
- خلفية: `bg-gradient-to-br from-amber-50 via-white to-amber-50`.

🔴 المهمة 4: أنيميشن احترافي

**المطلوب:**

**4.1 في `app/globals.css` أضف keyframes:**
```css
@keyframes fadeIn { from { opacity: 0 } to { opacity: 1 } }
@keyframes slideInFromRight { from { transform: translateX(100%); opacity: 0 } to { transform: translateX(0); opacity: 1 } }
@keyframes slideInFromTop { from { transform: translateY(-10px); opacity: 0 } to { transform: translateY(0); opacity: 1 } }
@keyframes scaleIn { from { transform: scale(0.95); opacity: 0 } to { transform: scale(1); opacity: 1 } }
@keyframes pulse-soft { 0%, 100% { opacity: 1 } 50% { opacity: 0.7 } }
@keyframes shimmer { 0% { background-position: -200% 0 } 100% { background-position: 200% 0 } }
```

**4.2 أضف Utility Classes:**
```css
.animate-fade-in { animation: fadeIn 0.3s ease-out }
.animate-slide-in { animation: slideInFromTop 0.3s ease-out }
.animate-scale-in { animation: scaleIn 0.2s ease-out }
.animate-pulse-soft { animation: pulse-soft 2s ease-in-out infinite }
.skeleton { background: linear-gradient(90deg, hsl(var(--muted)) 25%, hsl(var(--muted-foreground)/0.1) 50%, hsl(var(--muted)) 75%); background-size: 200% 100%; animation: shimmer 1.5s infinite }
```

**4.3 طبّق الأنيميشن في:**

**أ) الصفحات الجديدة:**
- عند الدخول لأي صفحة: `animate-fade-in` على `<main>`.

**ب) القوائم المنسدلة (Dropdown):**
- عند الفتح: `animate-scale-in origin-top-left`.

**ج) الـModal/Dialog:**
- عند الفتح: `animate-scale-in`.
- عند الإغلاق: `animate-fade-out`.

**د) البطاقات:**
- Hover: `transition-all duration-200 hover:shadow-md hover:-translate-y-0.5`.

**هـ) الأزرار:**
- `transition-all duration-150 active:scale-[0.98]`.

**و) الإشعارات (Toast):**
- عند الظهور: `animate-slide-in`.

**ز) الشارات:**
- `animate-pulse-soft` للأشياء الحية (مثل العداد).

**ح) Loading States:**
- استبدل `Spinner` بـ`skeleton` حيثما يناسب.

**4.4 احترم `prefers-reduced-motion`:**
```css
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```
