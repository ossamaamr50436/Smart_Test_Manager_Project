🔴 المهمة 2: إضافة زر الوضع الليلي (Dark Mode)

2.1 الفهم الحالي
next-themes مثبّت (ThemeProvider موجود في app/layout.tsx).

darkModeEnabled موجود في AppSettings (كقيمة افتراضية).

CSS يحتوي على .dark class (افتراضي من Tailwind).

2.2 المطلوب
أ) زر Toggle في الشريط العلوي:

في components/dashboard/dashboard-topbar.tsx:

tsx
import { useTheme } from "next-themes";
import { Moon, Sun } from "lucide-react";
import { useEffect, useState } from "react";

// داخل المكوّن:
const { theme, setTheme } = useTheme();
const [mounted, setMounted] = useState(false);
useEffect(() => setMounted(true), []);

// في الـJSX، قبل قائمة المستخدم:
{mounted && (
  <button
    type="button"
    onClick={() => setTheme(theme === "dark" ? "light" : "dark")}
    aria-label="تبديل الوضع الليلي"
    className="flex h-11 w-11 items-center justify-center rounded-md text-muted-foreground transition-colors hover:bg-secondary-200/40"
  >
    {theme === "dark" ? <Sun className="h-5 w-5" /> : <Moon className="h-5 w-5" />}
  </button>
)}
ب) التأكد من ThemeProvider:

افتح app/layout.tsx وتأكد:

tsx
<ThemeProvider
  attribute="class"
  defaultTheme={defaultTheme}
  enableSystem
  disableTransitionOnChange
  nonce={nonce}
>
  {children}
</ThemeProvider>
ج) التأكد من CSS Variables للـDark:

افتح app/globals.css وتأكد من وجود:

css
.dark {
  --background: ...;
  --foreground: ...;
  --primary: ...;
  --secondary: ...;
  --card: ...;
  --border: ...;
  --muted: ...;
  /* ... كل المتغيرات */
}
إذا لم تكن موجودة، أضف نسخة .dark مع ألوان داكنة مناسبة.

د) عرض الزر لكل الأدوار:

الزر موجود في dashboard-topbar.tsx وهو مشترك بين جميع الأدوار ✅.

سيظهر تلقائياً لكل من: SUPER_ADMIN، ADMIN، SPECIALIST، EXAMINER، INSTITUTION، HEAD_OF_AFFAIRS، CERTIFICATE_SOURCE.

2.3 التعامل مع darkModeEnabled (إعداد المنصة)
AppSettings.darkModeEnabled هو القيمة الافتراضية للمنصة.

إذا true → المستخدم الجديد يبدأ بـdark.

المستخدم يستطيع تبديله يدوياً (يُحفظ في localStorage عبر next-themes).

لا حاجة لتعديل AppSettings في هذه المهمة.

2.4 الاختبار
افتح المنصة → الزر ظاهر في Topbar (أيقونة قمر/شمس).

اضغطه → الوضع يتبدّل فوراً.

افتح صفحة جديدة → الوضع محفوظ.

أعد تحميل الصفحة → الوضع محفوظ.

جرّب في كل الأدوار → الزر يعمل.
